# Local GCRS polygon resolution with row-preserving OOJ output

This change replaces the former AgentSpace polygon handoff with a local, read-only SIW path that preserves physical input rows, resolves coordinates through guarded GRBI calls, retrieves station routes, classifies points, and writes standalone and daily-report outputs. Unique network work is separated from ordered result materialization, one transport session is shared across `/grbi`, `/gs`, and `/gr`, and Working Sheet AG is written directly by row. Four correctness gates still permit false not-found, false Outside, false `VERIFY OK`, or same-TID/different-station misalignment. The workspace has no `.git` metadata or Git executable, so scope was reconstructed from the dated 2026-09-18 implementation, its production call sites, authoritative docs, and regression suite rather than an exact base-branch diff.

Watch for: **confirmed** GRBI guard short-circuiting after a partial retry; **confirmed** malformed coordinates/geometries producing false Outside or escaping row-level handling; **confirmed** workbook verification accepting fewer outputs than inputs; and **confirmed** daily pair verification checking TID but not station.

**Verdict**: NEEDS_CHANGES

## High-level view

Every non-empty standalone input line becomes a sequenced object before validation. Numeric and DOC identifiers are deduplicated only for SIW, routed to ATS and ATA respectively, then expanded over the original sequence, preserving malformed rows, duplicates, and same-TID/different-station rows in the normal producer path.

A real `/gpsn` request gates mcscli; initial or later mcscli transport failure moves auto mode once to persistent Edge, whose owner thread serializes browser calls. GRBI is centralized and sequential in batches of 200, but a partial retry can bypass the remaining G1/G2/G3 checks and turn a degraded response into confirmed not-found.

Polygon prefetch deduplicates carrier/station pairs, refreshes daily data, retains separate route geometries, and evaluates longitude/latitude without unioning. Schema-invalid cache can suppress live refetch, while non-finite coordinates and malformed GeoJSON can become Outside or terminate the stage.

The standalone writer atomically replaces and reopens its workbook; the daily path creates one polygon row per Tech_Data row and writes AG directly. Standalone verification can approve fewer results than inputs, and template integration can accept station-swapped rows when duplicate TIDs match.

No executable path imports AgentSpace, accepts an AgentSpace option, or creates the former handoff. The remaining `GCRS Agentspaces ` sheet and `GCRS Agent Space` header are legacy Excel contracts; mcscli authorization, exact portal boundary parity, and station-source policy remain documented limitations rather than blockers.

### Sequence identity survives network deduplication

`parse_input_text` records source line and sequence before validation, requires exactly one tab, recognizes 12-digit and case-insensitive `DOC` identifiers, and retains malformed rows as explicit errors. `run_boundary_check` sends only valid canonical identifiers to GRBI, then emits one result per parsed object; the regression suite demonstrates duplicate pairs and one TID evaluated against two stations.

```text
physical input / ordered Tech_Data
        |
sequenced (TID, station) pairs -- malformed rows retain sequence
        |-- unique TIDs --> sequential ATS/ATA GRBI
        |-- unique carrier/station --> cache or /gs + /gr
        v
ordered classification --> standalone XLSX / polygon.csv --> Working Sheet AG
```

### One-way SIW selection leaks Edge after a failed probe

Data POSTs pass through the `gpsn`/`grbi`/`gs`/`gr` allowlist, use the fixed SIW host in production construction, and include browser credentials only against that origin. Auto mode validates a non-empty `/gpsn` response before retaining mcscli and retries a later mcscli transport failure through Edge; polygon workers queue browser work onto one owner thread.

A **confirmed, non-blocking robustness issue** occurs when Edge starts but its probe fails. `_activate_edge` assigns the transport only after `edge.probe()`, leaving neither it nor session cleanup a reference to close the browser worker (`tools/siw_client.py:326-335`). The run reports SIW unavailable, but the persistent profile can remain locked; close the local transport on probe failure.

A **confirmed, non-blocking documentation mismatch** remains in the endpoint claim. Edge startup also reaches fixed-host `/query` and `/sso/login` (`tools/siw_client.py:195-252`), so `Docs/polygon-checker.md` should call the four-item allowlist the permitted data POST routes, not the only routes reached by code.

### Partial GRBI recovery bypasses degraded-window guards

After a zero-row multi-ID response, the 2/4/6/8-second loop calls `_consume_retry`; any retry with one route row then returns before the `>=50 invalidIds` and missing-ID guards (`tools/gcrs_mcscli.py:127-154`). A **confirmed blocking correctness issue** results: a probe with 60 IDs, followed by one row plus 59 invalid IDs, made two calls and accepted all 59 as confirmed invalid after one sleep. The G2 recheck has the same reduced `_consume_retry` path, so another mass-invalid response is not re-evaluated.

This contradicts the requirement to re-verify every suspicious invalid block and can emit false `Error — TID not found in SIW`. Retry responses must re-enter one guard evaluator until each ID is resolved, trustworthy singleton-invalid, or unresolved after all guards.

### Cache and geometry validation do not enforce the published schema

A **confirmed, non-blocking cache-recovery issue** contradicts the rule that schema-invalid cache is ignored. `_validate_geometry` raises `RuntimeError`, but `_read_cache` does not catch it (`tools/polygon_check.py:90-113`); a cached `Point` probe raised without attempting SIW. The failure is visible and `--refresh-polygons` works around it, but normal standalone runs should discard and refetch invalid entries.

A **confirmed blocking classification issue** comes from shallow validation. Invalid short rings pass validation and become Outside, `float("nan")` GPS values also test Outside, and a malformed GeometryCollection child raises `AttributeError` outside the row-level catch (`tools/polygon_check.py:90-100,172-203,282-290`). Validate finite/ranged GPS and recursively validate rings, polygons, and collections so invalid source data always becomes `Error — Invalid polygon/GCRS data` and cannot abort unrelated rows.

Separate-route evaluation, `(longitude, latitude)` order, Polygon/MultiPolygon handling, outer-boundary inclusion, and hole-boundary exclusion match the authority. Exact portal parity for a known edge fixture remains an accepted limitation.

### `VERIFY OK` does not prove rows equal input

The reopened workbook is compared with `expected.results`, but no check proves `len(expected.results) == len(expected.inputs)`; the CLI logs `(VERIFY OK)` beside those counts unconditionally (`tools/tid_polygon_checker.py:295-327,368`). A **confirmed blocking correctness issue** follows: a probe with two inputs and one result returned `verify_ok=True`, `rows=1`, and `input_rows=2`.

Summary totals are also compared with `expected.summary`, not recalculated from reopened rows, and the `Rows == Input` summary value is not checked. Recalculate all counts from the workbook and fail before hashing or success logging on any row, identity, vocabulary, or total mismatch.

### AG row alignment proves TID but not station

The daily producer uses SCC Source with ticket station as fallback, forces polygon refresh, and emits rows in Tech_Data order (`tools/run_daily.py:323-343`). `fill_template` checks count and normalized TID, then writes status directly to AG; it never compares polygon Station with the effective station (`tools/fill_template.py:286-312`).

This is a **confirmed blocking correctness issue** for independent artifact validation and `rebuild_report.py`. A probe swapped ST1/ST2 polygon rows for two equal TIDs, and `fill` accepted them, allowing Inside/Outside to attach to the wrong row. Validate the full ordered `(TID, effective station)` pair and compare AG with polygon status during final readback.

Using SCC `Source` first matches the updated docs. Whether currentStationCode should replace it is explicitly open, so that policy is an accepted limitation; failing to verify the chosen policy is not.

### AgentSpace is absent from the runtime graph

Production search found no AgentSpace client, import, option, or handoff. All callers delegate GRBI to the shared local engine, and polygons come from the shared SIW session. `tickets_pull.py` cites inherited rules and `fill_template.py` retains a fixed worksheet name; neither is a runtime dependency.

### Tests stop before the authoritative failure modes

The suite reports 7/7 passing for row preservation, ATS/ATA routing, no-union gap behavior, initial probe fallback, sequential/deduplicated lookup, direct AG writes, different-TID rejection, and handoff removal. A **confirmed, non-blocking coverage gap** remains for G1/G2/G3 responses, partial retries, invalid-cache refetch, malformed/non-finite geometry, unequal workbook counts, summary recomputation, station-swapped duplicate TIDs, late fallback, and failed Edge-probe cleanup (`tests/test_polygon_workflow.py:90-258`). Add these regressions with the fixes; the green suite does not support the broader guard and verification claims in `Docs/implementation.md`.

### Accepted limitations

The currently unauthorized mcscli path is handled by the required real probe and Edge fallback. Standalone cache has no freshness TTL by design, while callers can refresh and daily runs always do. Exact boundary parity awaits a known portal fixture, SCC station source remains a business decision, and legacy AgentSpace text is required by fixed workbook contracts.
